# Hetzner Compute

Template and example code for running ephemeral multi-server compute tasks on Hetzner Cloud.

## Layout

```
hetz-compute/    Base Terraform template
queued-example/  Example project using a work queue
sharded-example/ Example project using a sharded work distribution
```

## Usage

Copy the `infra_template/` directory to your project and customize per your needs.

Follow the conventions in the example projects to build your own.
